# 포켓몬 케이스 배그 PC 조립 계획

클라우드 세션에서 사양을 정하고, 로컬 Claude Code에서 2026-10-13에 가격 조회와 최종 구매 목록 확정까지 마쳤다.
조회 원자료(플랫폼별 가격표·링크·사양 출처)는 `pc-build/research/`에 있다.

## 목표
- 용도: 게이밍 PC, 주 게임은 **배틀그라운드**
- 1차 목표: 배그 저사양이라도 원활히 구동. 이후 돈 생기면 하나씩 업그레이드
- **DDR5로 가지 않음** (램값이 비쌈) → DDR4 유지, **AM4 B550M** 플랫폼으로 확정
- 소음은 최소화 (사용자가 소음을 싫어함)

- 메인보드: **M-ATX / Mini-ITX만** (ATX 불가, BTF 호환)
- VGA 410mm, 공랭 쿨러 160mm, 라디에이터 상단 120/240/360 · 후면 120
- 기본 팬: ARGB 120mm × 3 (측면 흡기 2, 후면 배기 1), 팬 전원 IDE 4핀(몰렉스)
- 저장장치: 2.5" SSD 1 + HDD 2, PSU 최대 240mm
- 상단 I/O: USB-C(3.2), USB 3.0 × 2, 마이크, 오디오, LED 버튼
- 가격: 세 캐릭터 모두 **49,000원 무료배송** (컴퓨존 스마트스토어·쿠팡·주연테크 공식 스토어, 2026-10-13). 11번가 9447896161은 현재 163,250원으로 올라 제외

### 부품별 대안
- **메인보드 MSI MAG B550M MORTAR (박격포, Wi-Fi 없음)**: 후보 중 **전면 USB-C 헤더가 있는 유일한 보드**라서, 케이스 상단 USB-C 포트를 쓰려면 이 보드를 골라야 한다. Flash BIOS 버튼도 있다. 국내 신품은 단종되어 해외구매만 있다. 중고 시세는 중고나라 132,000원(무료배송), 번개장터 134,000원(129,000 + 배송 5,000, 최신 BIOS 명시)이다. A안보다 약 3만 원 비싸다
- **메인보드 ASRock B550M Pro RS** (Pro4 후속): 신품 120,320원(네이버 최저 117,820 + 배송 2,500)이다. 전면 USB-C 헤더가 없고 팬 헤더도 4개뿐이라 Pro4보다 나은 점이 없다
- **메인보드 ASUS TUF GAMING B550M-PLUS**: 신품 149,000~161,500원이다. 바이오스 플래시백은 있지만 전면 USB-C 헤더가 없고 팬 헤더가 4개뿐이며(CPU, CPU_OPT, CHA×2) ARGB 헤더도 1개라 제외했다
- **저가형 수랭 중 더 조용한 제품**: DEEPCOOL LE360 V2 화이트, 85,010원(다나와)이다. 팬 최대 31.6dBA, 펌프 21dBA로 ICEROCK(팬 최대 34.91dBA)보다 조용하다. A안보다 +17,610원
- **디스플레이형 다른 후보**: 발키리 GLA-360 DIGITAL 화이트(101,570원, 숫자 온도 표시), 앱코 포세이돈 P360L LCD 화이트(128,000원), 발키리 B360 LCD 화이트(130,500원), 쿨러마스터 ATMOS II LCD 화이트(202,120원)
- **CPU 중고**: 중고나라 "라이젠 5600 cpu 새것" 137,000원, 번개장터 150,000~160,000원이다. 신품과 2만 원 정도 차이라 보증을 생각하면 신품이 낫다

## 쿨러·팬 결선 계획 (Pro4 기준, 소음 최소화)
- 수랭 펌프 → `CPU_FAN2/WP`
- 라디에이터 팬 3개 → 수랭 동봉 분배 케이블 → `CPU_FAN1` (PWM 곡선은 CPU 온도 기준)
- 케이스 팬 3개 → `CHA_FAN1~3` (개별 PWM 또는 DC 제어)
- ARGB: 수랭 → `ARGB1`, 케이스 팬 데이지체인 → `ARGB2`
- B안 LCD 수랭은 내부 USB 2.0 헤더에 연결해야 화면이 켜진다. 온도 표시는 전용 프로그램 "FX LCD Series Software"(Windows)로 설정한다
- 라이젠 5600은 65W라 부하가 낮을 때는 팬을 저속으로 돌릴 수 있다. BIOS에서 팬 곡선을 완만하게 잡는다

### 기본 케이스 팬(몰렉스 전원) 처리
웹에서는 기본 팬 결선 정보를 찾지 못했다. 케이스가 도착하면 직접 확인한다.
1. 팬 케이블 끝이 3핀/4핀 팬 커넥터이고 몰렉스 변환 젠더만 끼워져 있는 경우: 젠더를 빼고 보드 `CHA_FAN` 헤더에 연결한다. 3핀이면 BIOS에서 DC 모드로 설정한다 → **추가 비용 0원**
2. 팬이 몰렉스나 케이스 LED 컨트롤러에 직결되어 있는 경우: 항상 12V 최고 속도로 돈다 → 써멀라이트 TL-C12CW-S 5팩(38,050원)으로 교체한다. 시중의 몰렉스→팬 변환 젠더는 전원만 줄 뿐 속도 조절은 안 된다
3. 케이스 LED 버튼은 교체한 팬에는 적용되지 않는다. 조명은 보드 ARGB 소프트웨어(ASRock Polychrome)로 맞춘다

## 구매 전 확인할 것
- **ASRock B550M Pro4의 출고 BIOS**: 플래시백이 없어서, 출고 BIOS가 5600(2022년 출시)을 지원하지 않으면 부팅되지 않는다. 판매처에 BIOS 버전을 문의하거나 ASRock CPU 지원 목록에서 5600 지원 최소 버전을 확인한다(미확인)
- **ICEROCK CL-360**: AM4 브래킷 포함, 라디에이터 396 × 120 × 27mm (다나와 사양). 상단 360 장착 가능 범위 안이다
- **FX360 LCD**: USB 2.0 헤더가 필요하다(2차 출처). SATA 전원 필요 여부는 미확인
- 중고 메인보드를 산다면 BIOS 버전, 슬롯·핀 손상, 백패널 실드 포함 여부를 확인한다

## 업그레이드 로드맵 (DDR4 · B550M · 750W 유지)
2026-10-13 시세를 반영해 고쳤다.
1. 그래픽카드 → **RTX 5070** (5060 Ti 16GB보다 5만 원 정도 비쌀 뿐이라 5060 Ti는 건너뛴다)
2. 모니터 → 듀얼(현재 FHD 320Hz + 27" QHD) 또는 34" UWQHD 커브드 (UWQHD는 RTX 5070 이상 권장). 시세는 아직 조사하지 않았다
3. CPU → **라이젠7 5700X3D는 보류.** 단종으로 신품이 58~64만 원이라 AM5용 9800X3D(60만 원대)보다 비싸다. 중고(현재 45만 원)가 30만 원 안쪽으로 내려오면 그때 구매한다
4. (선택) 그래픽카드 → **RTX 5070 Ti** (750W 기준 권장 최대)

## 조회 범위와 한계
- 신품: 다나와(가격비교 스크립트), 네이버 가격비교(Aside로 통합검색 쇼핑 탭 조회), 쿠팡(검색 API), 컴퓨존·G마켓·11번가·옥션(다나와·네이버 경유)
- 중고: 번개장터, 중고나라 (Aside로 조회). 당근은 거주 지역을 몰라 조회하지 않았다
- 네이버쇼핑 스킬의 호스팅 프록시는 네이버 API 404(SE05)로 동작하지 않는다. 네이버 개발자센터 검색 API 키를 발급받으면 직접 호출할 수 있다
