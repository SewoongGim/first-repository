# 포켓몬 케이스 배그 PC 조립 계획

클라우드 세션에서 사양을 정하고, 로컬 Claude Code에서 2026-10-13에 가격 조회, 헤더 검증, 최종 구매 목록 확정까지 마쳤다.
조회 원자료(플랫폼별 가격표·링크·사양 출처)는 `pc-build/research/`에 있다.

## 목표와 조건
- 용도: 게이밍 PC, 주 게임은 **배틀그라운드**
- 1차 목표: 배그 저사양이라도 원활히 구동. 이후 돈 생기면 하나씩 업그레이드
- **DDR5로 가지 않음** (램값이 비쌈) → DDR4 유지, **AM4 B550** 플랫폼
- **케이스 전면 USB-C를 쓴다** → 메인보드에 전면 USB Type-C 헤더가 반드시 있어야 한다
- 팬·펌프·ARGB·LCD 수랭 USB를 전부 메인보드에 꽂을 때 **헤더가 모자라는 경우가 없어야 한다**
- 소음은 최소화. 중고도 괜찮다 (당근은 천안·아산)

## 케이스: 주연테크 포켓몬스터 ARGB BTF 미니타워 (피카츄 / 꼬부기 / 뮤)
- 218(W) × 420(D) × 395(H) mm, 6kg, **M-ATX / Mini-ITX만** (ATX 불가, BTF 호환)
- VGA 410mm, 공랭 쿨러 160mm, 라디에이터 상단 최대 360, PSU 최대 240mm
- 기본 팬: ARGB 120mm × 3 (측면 흡기 2, 후면 배기 1)
- 상단 I/O: LED ON/OFF 버튼, USB Type-C, USB 3.0 × 2, 헤드셋/마이크, 전원/리셋 (리뷰 사진·스펙표로 확인)
- 내부에 **ARGB 허브**가 있다. 허브에 메인보드 5V 3핀 ARGB를 꽂으면 보드 조명과 동기화되고, 꽂지 않으면 LED 버튼으로 기본 효과를 고른다 (네이버 블로그 리뷰 2건으로 확인)
- **전면 USB-C 케이블 = 20핀 Type-C 전용 단자(Key-A) (2026-10-15 블로그 사진 2건으로 확인).** 케이스에서 나오는 케이블은 납작한 20핀 Type-C 플러그, 19핀 USB 3.0 블록, HD AUDIO, 통합 F_PANEL이다(네이버 블로그 chudu/224075431208 14번 사진, dustlover/224083960816 7번 사진). → 전면 Type-C 헤더가 없는 보드(Pro RS 등)에서는 전면 USB-C를 못 쓴다
  - **2026-10-15 케이스 도착, 실물 사진으로 재확인:** 납작한 흰색 리본 케이블 끝에 금색 접점이 드러난 20핀 Type-C(Key-A) 플러그. Pro RS에 꽂을 곳이 없으므로 메인보드 트레이 뒤로 묶어 둔다. 살릴 방법은 둘 다 비추천: ① 19핀→20핀 변환 젠더(다나와 1만~2만 원대, 해외 판매자)는 보드의 유일한 19핀 헤더를 차지해 전면 USB-A 2개가 죽는다 ② PCIe Type-E 확장카드(다나와 4만~8만 원, 해외 판매자)는 매뉴얼 배치도상 PCIE2(x1)는 PCIE1 두 칸 아래, PCIE3(Gen3 x4)는 세 칸 아래다. 2슬롯 3070이면 PCIE2가 비지만 그래픽카드 팬 바로 앞을 막고, 2.5슬롯 이상이면 PCIE2가 덮인다. 보유 3070은 HP OEM 듀얼 슬롯(2026-10-16 확인)이라 PCIE2는 비지만 팬 바로 앞이라 여전히 비추천
- 상단 360 수랭은 지원하지만 공간이 넉넉하지 않아 "튜닝 램과의 간섭도 고려해야 한다"는 리뷰가 있다(mykgh44/224076289666). 램 방열판(RH-1 EVO) 높이와 상단 라디에이터+팬 간섭은 실물로 꼭 확인한다
- 확인 못 한 것: 허브 전원 단자(SATA/몰렉스), 기본 팬 커넥터(PWM 여부). 실물로 확인한다
  - 허브 전원 확인법: 허브(트레이 뒤 작은 기판)에서 나오는 케이블 중 납작하고 넓은 L자 15핀(SSD 전원과 같은 모양)이 있으면 SATA 전원, 큰 사각 4핀이면 몰렉스, 3핀 ARGB(보드 ADDR_LED용)와 팬 헤더용 4핀만 있으면 보드에서 전원을 받는다. 보드를 연결하지 않아도 LED 버튼만으로 조명이 켜진다는 리뷰가 있어 자체 전원(SATA)일 가능성이 높지만 추정이다
  - 24핀 180도 어댑터용: 보드 24핀 위치(보드 오른쪽 끝) 바로 옆 트레이에 케이블 구멍이 있는지 확인
  - **2026-10-15 실물 사진:** 트레이 뒤에 별도 허브 기판은 보이지 않는다. 후면 팬 쪽 케이블 묶음에 큰 흰색 4핀 커넥터(몰렉스로 보임), 4가닥 4핀 커넥터(팬 PWM으로 보임), 3구멍 커넥터(5V ARGB로 보임), 흑백 2가닥 "RESET SW" 라벨 2핀이 있다. 바닥에는 측면 팬 쪽 소형 연결 커넥터(3핀, 4핀)가 풀려 있다. 판독은 사진 확대 기준이라 커넥터 정면 사진으로 확정해야 한다
  - 정황: ARGB 헤더가 없는 H610M K 보드에서도 팬 조명이 기본 효과로 켜졌다는 후기(chudu/224075431208)와 몰렉스 커넥터가 있다는 점으로 보아, 조명 전원은 파워 몰렉스에서 받는 구조로 추정한다(미확정). 이 경우 보드 ARGB 헤더에는 신호만 걸려 5V 3A 한도 부담이 작다
  - RESET SW 2핀은 조명 컨트롤러의 버튼 입력으로 보이며, 상단 LED 버튼의 LED SW 2핀(암)과 짝일 가능성이 있다(미확정, 핀 모양과 설명서로 확인)
  - 파워(Classic II 750W 골드 풀모듈러)에 IDE 4핀(몰렉스) 4개가 있어 몰렉스 전원은 문제없다(다나와 스펙 58913891, 12487214)
  - **2026-10-15 확정 (주연테크 "ARGB팬 연결 방법" 안내 그림, 네이버 블로그 it_gamemaker/224076400931 6번째 이미지 + 실물 사진):** 허브 기판 없이 후면 팬 케이블 묶음이 컨트롤러 역할을 한다
    1. 서브팬 데이지 체인: 측면 팬 2개의 걸쇠 커넥터를 같은 모양끼리 이어 후면 팬 묶음의 4핀 걸쇠 커넥터까지 연결
    2. 팬 속도: 묶음의 3구멍 커넥터를 보드 팬 헤더에 꽂는다(DC 방식). **안 꽂으면 팬이 돌지 않는다**
    3. ARGB: 홈 파인 3구멍 커넥터를 보드 ADDR_LED에. LED 버튼을 3초 이상 누르면 보드 동기화 모드로 바뀐다
    4. LED 버튼: 상단 LED 버튼의 LED SW와 묶음의 RESET SW가 짝. 끼워진 상태로 배송됨(사용자 확인) → 그대로 둔다. 보드의 RESET 핀과는 무관
    5. 전원: 몰렉스를 파워 IDE 4핀에. **조명 전원은 몰렉스**라 보드 ARGB 헤더에는 신호만 걸린다(5V 3A 한도 걱정 없음)
- 가격: 세 캐릭터 모두 49,000원 무료배송이었으나 **쿠팡에서 39,000원에 구매함(2026-10-13)**

### 선택: ASRock B550M Pro-A (대원씨티에스, 신품)
- 다나와 최저 110,300원 (피시포올 107,800 + 배송 2,500), 네이버 최저 110,520원, 쿠팡 112,000원
- 매뉴얼 v1.0이 2026년 1월 발행된 최신 보드라 출고 BIOS가 라이젠 5000 시리즈를 지원한다(매뉴얼 CPU 지원 항목에 Vermeer 명시). 5600을 먼저 꽂으면 그 상태로 BIOS를 올릴 수 있어서 플래시백이 없어도 된다. 나중에 X3D로 바꿀 때는 BIOS를 먼저 최신으로 올린다
- MORTAR 중고는 플래시백과 전용 펌프 헤더가 있지만, 보증이 없고 2~3만 원 더 비싸다
- **ASRock B550M Pro RS (흰색·은색 디자인, 피시포올 167995, 124,000원, 2026-10-15):** 매뉴얼로 확인한 차이는 전면 Type-C 헤더가 없는 것 하나뿐이다. 팬 헤더(CPU_FAN1 + CHA_FAN1~3/WP), ARGB 2개(ADDR_LED1·2), RGB 12V 2개, USB 2.0 헤더 2개, M.2 구성(M2_1 Gen4 x4 / M2_2 Gen3 x2)은 Pro-A와 같다. 대신 2.5G LAN, DP 1.4, 두 번째 x16 슬롯(Gen3 x4)이 있다. 보드 크기 24.4×24.4cm
  - 케이스 전면 USB-C가 19핀 USB 3.0 케이블에 같이 묶여 있으면 Pro RS로도 잃는 것이 없다. 20핀 Type-C 전용 케이블이면 전면 USB-C를 못 쓴다(19→20핀 변환 젠더를 쓰면 대신 전면 USB-A 3.0 두 개가 죽고, PCIe Type-E 확장카드는 4만~10만 원 해외직구라 비효율)
  - → 케이스 전면 USB-C 케이블 끝 모양을 먼저 보고 정한다
- **화이트 B550M 국내 신품은 Pro RS 하나뿐 (2026-10-15):** 스틸레전드·BIOSTAR B550M SILVER는 단종(다나와 가격 없음, 해외 24만~30만), GIGABYTE B550M X AORUS ELITE는 검정. 피시포올 Pro RS: 디앤디컴 124,000 / 에즈윈 128,220 / 대원씨티에스 129,000. 다나와 최저 대원 119,260(다른 몰). 사용자는 전면 USB-C보다 흰색 보드를 우선함
- **화이트 B550M (2026-10-15 조사):** 국내 신품은 없다. 해외 직구로 ASRock B550M Pro SE 화이트(15만~28만)와 Colorful CVN B550M GAMING FROZEN V14/V15(14만~35만)가 있지만, 둘 다 전면 USB-C 헤더가 확인되지 않는다(Pro SE는 리테일 스펙상 USB 3.2 Gen1 헤더 1개 + USB 2.0 헤더 2개뿐, FROZEN은 Type-C가 후면 포트). 국내 A/S도 없다 → Pro-A 유지

#### 보유 3070 = HP OEM (2026-10-16 사용자 사진으로 확인)
- 기판 라벨: `AS# M27699-003`, `REV. 0A`. 해외 판매처들이 이 번호를 HP 브랜드 RTX 3070 8GB GDDR6(PCIe 4.0 x16, 소비전력 220W, 듀얼 슬롯)로 판다. HP 공식 사양서는 못 찾았다
- **전원 단자는 8핀이 아니라 12핀 하나(2열 6행)다.** 사진에서 핀 간격이 일반 PCIe 8핀보다 촘촘해 RTX 30 FE와 같은 계열의 미니 12핀으로 본다
- **연결 방법: 파워의 PCIe 8핀 케이블 2가닥 → "8핀 2개(암) → 미니 12핀(수)" 어댑터 → 카드.** 8핀 두 개는 각각 다른 케이블로(한 가닥에 달린 데이지 체인 두 끝 말고) 꽂는다. HP 커뮤니티 답변도 HP OEM 3070에 "2 x 8-pin to 12-pin PCIe power adapter"가 필요하다고 했고(검색 결과 요약, 원문 페이지는 403으로 직접 확인 못 함), Jawa 중고 매물도 "12핀 전원 어댑터가 빠져 있어 따로 사거나 커스텀 케이블을 써야 한다"고 적었다
- **파워의 12V-2x6 케이블을 바로 꽂지 않는다.** 30 시리즈 12핀은 센스핀이 없는 다른 단자라는 포럼 답변(Tom's Hardware)이 있고, 꽂혀도 된다는 제조사 문서는 없다
- 어댑터 후보(다나와, 11번가 해외 판매자, 2026-10-16): 16AWG 15cm "PCIE 2x8핀 여성 → 미니 12핀 남성"(TH201_9682128563, 29,600), "듀얼 PCIe 8핀 암 → 미니 12핀 수, RTX 30 시리즈"(TH201_9674025686, 18,530). 배송 기간은 미확인. 국내 정품 대리점 상품은 다나와 검색에서 못 찾았다
- 미확인: HP OEM 12핀의 핀 배열이 엔비디아 FE 12핀과 같다는 제조사 문서. 카드를 받을 때 어댑터가 같이 왔는지 먼저 확인하고, 같이 왔으면 그걸 쓴다
- 듀얼 슬롯이므로 PCIE2(x1)는 비지만 그래픽카드 팬 바로 앞이라 확장카드를 꽂으면 바람을 막는다. 전면 Type-C용 PCIe 카드는 계속 비추천
