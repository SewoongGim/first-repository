# 포켓몬 케이스 배그 PC 조립 계획

클라우드 세션에서 사양을 정하고, 로컬 Claude Code에서 2026-10-13에 가격 조회, 헤더 검증, 최종 구매 목록 확정까지 마쳤다.
조회 원자료(플랫폼별 가격표·링크·사양 출처)는 `pc-build/research/`에 있다.

## 목표와 조건
- 용도: 게이밍 PC, 주 게임은 **배틀그라운드**
- 1차 목표: 배그 저사양이라도 원활히 구동. 이후 돈 생기면 하나씩 업그레이드
- **DDR5로 가지 않음** (램값이 비쌈) → DDR4 유지, **AM4 B550** 플랫폼
- **케이스 전면 USB-C를 쓴다** → 메인보드에 전면 USB Type-C 헤더가 반드시 있어야 한다
- 팬·펌프·ARGB·LCD 수랭 USB를 전부 메인보드에 꽂을 때 **헤더가 모자라는 경우가 없어야 한다**
- 소음은 최소화. 중고도 괜찮다 (당근은 천안·아산)

## 케이스: 주연테크 포켓몬스터 ARGB BTF 미니타워 (피카츄 / 꼬부기 / 뮤)
- 218(W) × 420(D) × 395(H) mm, 6kg, **M-ATX / Mini-ITX만** (ATX 불가, BTF 호환)
- VGA 410mm, 공랭 쿨러 160mm, 라디에이터 상단 최대 360, PSU 최대 240mm
- 기본 팬: ARGB 120mm × 3 (측면 흡기 2, 후면 배기 1)
- 상단 I/O: LED ON/OFF 버튼, USB Type-C, USB 3.0 × 2, 헤드셋/마이크, 전원/리셋 (리뷰 사진·스펙표로 확인)
- 내부에 **ARGB 허브**가 있다. 허브에 메인보드 5V 3핀 ARGB를 꽂으면 보드 조명과 동기화되고, 꽂지 않으면 LED 버튼으로 기본 효과를 고른다 (네이버 블로그 리뷰 2건으로 확인)
- 확인 못 한 것: 허브 전원 단자(SATA/몰렉스), 기본 팬 커넥터(PWM 여부), 전면 USB-C 케이블 끝 모양(20핀 Type-C 헤더용인지, 19핀 USB 3.0 공용인지). 공개 자료에 없어서 실물로 확인한다. 아래 보드는 두 경우 모두 꽂을 수 있다
- 가격: 세 캐릭터 모두 49,000원 무료배송이었으나 **쿠팡에서 39,000원에 구매함(2026-10-13)**

### 선택: ASRock B550M Pro-A (대원씨티에스, 신품)
- 다나와 최저 110,300원 (피시포올 107,800 + 배송 2,500), 네이버 최저 110,520원, 쿠팡 112,000원
- 매뉴얼 v1.0이 2026년 1월 발행된 최신 보드라 출고 BIOS가 라이젠 5000 시리즈를 지원한다(매뉴얼 CPU 지원 항목에 Vermeer 명시). 5600을 먼저 꽂으면 그 상태로 BIOS를 올릴 수 있어서 플래시백이 없어도 된다. 나중에 X3D로 바꿀 때는 BIOS를 먼저 최신으로 올린다
- MORTAR 중고는 플래시백과 전용 펌프 헤더가 있지만, 보증이 없고 2~3만 원 더 비싸다

## 헤더 배치도 (ASRock B550M Pro-A)
| 헤더 | A안 (LE360 V2) | B안 (FX360 LCD) |
|---|---|---|
| CPU_FAN1 (1A) | 수랭 **펌프** (BIOS에서 Full Speed) | 후면 배기 팬 |
| CHA_FAN1 (2A) | 수랭 라디에이터 팬 3개 (한 가닥) | 수랭 펌프+팬 공용 PWM |
| CHA_FAN2 (2A) | 측면 흡기 팬 2개 (Y 분배 케이블) | 측면 흡기 팬 1 |
| CHA_FAN3 (2A) | 후면 배기 팬 | 측면 흡기 팬 2 |
| ADDR_LED1 (5V) | 수랭 ARGB | 수랭 ARGB |
| ADDR_LED2 (5V) | 케이스 ARGB 허브 입력 (조명 동기화) | 케이스 ARGB 허브 입력 |
| USB32_TC2 (20핀) | 케이스 전면 USB-C | 케이스 전면 USB-C |
| USB 3.2 Gen1 19핀 | 케이스 전면 USB 3.0 × 2 | 케이스 전면 USB 3.0 × 2 |
| USB 2.0 헤더 2개 | 비어 있음 | 1개에 FX360 LCD, 1개 여유 |

- 펌프를 1A 헤더(CPU_FAN1)에, 팬 묶음을 2A 헤더(CHA_FAN)에 두어 전류 여유를 확보했다. CPU_FAN1에 무언가 연결되어 있어 BIOS의 CPU 팬 경고도 뜨지 않는다
- 기본 케이스 팬이 허브 전원으로만 돌고 보드에 꽂을 수 없으면, 팬은 최고 속도로 고정된다. 이때 CHA_FAN2·3은 비고, 소음이 거슬리면 TL-C12CW-S로 바꿔 위 표대로 꽂는다
- 케이스 전면 USB-C가 19핀 USB 3.0 공용 방식이어도 Pro-A에 19핀 헤더가 있어 문제없다

## 중고 세트·반본체·완본체·신품 번들 검토 (2026-10-13)
