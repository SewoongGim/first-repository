# 포켓몬 케이스 배그 PC 조립 계획 (인수인계 문서)

클라우드 세션에서 정리한 내용. 로컬 Claude Code에서 이 파일을 읽고 **가격 조회 → 최종 구매 확정**을 이어서 진행한다.

## 목표
- 용도: 게이밍 PC, 주 게임은 **배틀그라운드**
- 1차 목표: 배그 저사양이라도 원활히 구동. 이후 돈 생기면 하나씩 업그레이드
- **DDR5로 가지 않음** (램값이 비쌈) → DDR4 유지, **AM4 B550M** 플랫폼으로 확정

## 보유 부품 (재사용)
| 부품 | 모델 | 비고 |
|---|---|---|
| 그래픽카드 | MSI GTX 1080 8GB | 당분간 사용. RTX 3060 8GB는 다른 PC에서 사용 중 |
| 램 | 삼성 DDR4 PC4-25600(3200) 16GB × 2 | 방열판 없는 로우 프로파일 → 수랭 라디에이터 간섭 걱정 적음 |
| 파워 | 마이크로닉스 Classic II 골드 풀모듈러 750W ATX 3.1 | RTX 5070 Ti까지 OK. 12V-2x6 단자 있음 |
| SSD | **M.2 1개만 사용** (삼성 4TB M.2 추천, 또는 Lexar NM790 1TB) | |
| 모니터 | 한성 TFG24F32P (24" FHD Fast IPS 320Hz, HDMI 2.0 / DP 1.4) | DP로 연결해야 320Hz |

## 케이스: 주연테크 포켓몬스터 ARGB BTF 미니타워 (피카츄 / 꼬부기 / 뮤)
- 상세 이미지 기준 사양: 218(W) × 420(D) × 395(H) mm, 6kg
- 메인보드: **M-ATX / Mini-ITX만** (ATX 불가, BTF 호환)
- VGA 410mm, 공랭 쿨러 160mm, 라디에이터 상단 120/240/360 · 후면 120
- 기본 팬: ARGB 120mm × 3 (측면 흡기 2, 후면 배기 1), 팬 전원 IDE 4핀(몰렉스)
- 저장장치: 2.5" SSD 1 + HDD 2, PSU 최대 240mm
- 상단 I/O: USB-C(3.2), USB 3.0 × 2, 마이크, 오디오, LED 버튼
- 판매처 예: 11번가 상품번호 9447896161 (2026-10 다나와 기준 61,580원 표시). 주연테크 공식몰(Cafe24 이전 후)에는 케이스 미등록

## 업그레이드 로드맵 (DDR4 · B550M · 750W 유지)
1. 그래픽카드 → RTX 5060 Ti 16GB 또는 **RTX 5070**
2. 모니터 → 듀얼(현재 FHD 320Hz + 27" QHD) 또는 34" UWQHD 커브드 (UWQHD는 RTX 5070 이상 권장)
3. CPU → **라이젠7 5700X3D** (AM4 최종, 배그에 유리)
4. (선택) 그래픽카드 → **RTX 5070 Ti** (750W 기준 권장 최대)

## 로컬에서 이어서 할 일
1. 다나와 등에서 **현재 최저가 조회**: 라이젠5 5600, 위 B550M 후보 3종(Wi-Fi 없는 모델), 360mm 화이트 수랭 후보, 포켓몬 케이스
2. 메인보드 후보별 사양 확인: USB-C 전면 헤더 / 바이오스 플래시백 / AIO_PUMP 헤더 / 출고 바이오스의 5600·5700X3D 지원
3. 최종 1개씩 골라 **구매 목록 + 총액** 표로 확정
4. (선택) 업그레이드 부품(RTX 5070, 5700X3D, 모니터) 현재 시세도 같이 기록
