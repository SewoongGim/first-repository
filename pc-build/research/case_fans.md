## 3. 실패/미조회 플랫폼

- 다나와 `danawa_search.py`: 초기에 bs4 미설치로 실패 -> pip 설치 후 `python` (-I 없이) 실행으로 검색 성공. offers는 빈 결과.
- 번개장터: playwright 브라우저 미설치 -> `npx playwright install chromium` 후 CLI 실행은 성공했으나 결과 품질 낮음(위 참조).
- 당근: `daangn_used_goods.py`가 SSL "EE certificate key too weak" 오류로 지역 API 호출 실패 (불당동/효자동 모두 실패). 미조회.
- 11번가·G마켓·에누리 직접 조회: 시간 제약으로 미수행 (다나와 검색 노출가로 대체).
- Naver 쇼핑: 제외(메인 스레드 Aside 담당).

## 4. 팬 배선 조사

- 웹검색("주연테크 포켓몬스터 ARGB BTF 미니타워 팬 몰렉스 연결 소음", "팬 허브 ARGB 컨트롤러 리뷰"): 주연테크 제품 팬 배선·허브·소음 리뷰를 **찾지 못함**.
- 확인 불가 항목: 팬 커넥터 형태(3핀/4핀/몰렉스 직결), 내장 허브 존재 여부, 팬 전원 경로, ARGB 메인보드 연동 가능 여부, RPM/dB 사양, 소음 후기.
- 추정(확인되지 않음, 신뢰도 낮음): LED 버튼이 있어 ARGB 컨트롤러 보드가 있을 가능성이 있음. 다만 근거 없음.
- 사용자가 실물에서 확인할 것:
  1. 팬 케이블 끝이 4핀(PWM)/3핀인지, 몰렉스인지.
  2. 케이스 내부(상단/후면)에 팬 허브 보드가 있는지, 허브에 ARGB 3핀 헤더와 SATA/몰렉스 전원 입력이 있는지.
  3. 팬 라벨의 정격 RPM·dB·전압(12V) 확인.
  4. 허브 입력 전원이 SATA인지 몰렉스인지.

- 몰렉스 직결 팬을 몰렉스 변환 케이블로 메인보드 헤더에 꽂으면 속도 제어 기능이 없음(12V 고정). 속도 제어를 하려면 팬 자체가 PWM 4핀 또는 3핀 DC 제어 지원이어야 함. 몰렉스 팬을 보드 헤더에 연결하는 방식은 대부분 동작하지 않음.
- 보드 헤더 1개당 전류 한도는 보통 1A 내외. 120mm 팬 3개는 여유 있으나 360 AIO(펌프 포함)를 추가하면 헤더 분배 여부 검토 필요.
- 360 AIO 기준 팬 6개 + 펌프 1개.
