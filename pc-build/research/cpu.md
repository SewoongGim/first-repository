## 2. Ryzen 5 5600 중고

**신뢰 가능한 중고 시세 확보 실패.**

- 번개장터(bunjang-cli): `npx bunjang-cli` 실행 시 Playwright 브라우저(chromium_headless_shell) 미설치로 중단. 직접 API(api.bunjang.co.kr/api/1/find_v2.json)는 404 응답.
- 당근 (daangn_used_goods.py): 스크립트가 JSON이 아닌 응답을 받아 파싱 실패(불당동·효자동 모두). daangn.com 직접 curl은 Windows Schannel 인증서 폐기 확인 오류(CRYPT_E_NO_REVOCATION_CHECK)로 실패.
- 중고나라/퀘이사존/쿨엔조이: 이번 세션에서 미조회(검색 도구 우선순위에서 제외되거나 로그인 필요 가능성).
- 따라서 5600 중고 목록·매물 링크·가격은 제공 불가.
